# bot/

## Responsibility
Core trading engine — sole live-trading domain (42 Python modules). Owns the 10 s main loop (`main.py:212`), signal generation, entry filter chain, risk sizing, order placement/exit tree, single-source-of-truth analytics, indicator math, backtesting (vectorized + Numba JIT twin), ML feature/ensemble training, optimization, and global mutable state. The deprecated `trend_bot.py:1` is a 12-line wrapper delegating to `main.main()` — preserved only for reference.

## Design

**Architecture style:** Modular monolith with module-level singletons (no DI). `state.py:1` is the global registry — 30+ dicts/vars (`_scale_out_state:54`, `_chandelier_state:55`, `_ml_models:57`, `_rate_cache:104`, `_pending_limits:126`, `_regime_gate_state:127`, `_filter_stats:94`) persisted via table-driven `PERSISTED:178` (`_serialize:208`/`_coerce:227`/`save_bot_state:273` atomic `.tmp`+`fsync`+`replace`, `load_bot_state:287` tolerant coalesce).

**Key patterns:**
- **Strategy dispatch — MA type** (`indicators.py:calc_ma` dispatch `kama|vidya|ema` via `cfg["ma_type"]`; `signals.py:get_signal`/`get_mtf_fused_signal`, `backtest.py:_precompute`). KAMA for non-crypto (XAU/US30/GBPJPY), VIDYA for crypto (BTC/SOL/XRP). `calc_kama:ER→SC`, `calc_vidya:CMO-weighted SC`, `calc_ma_slope:raw delta`.
- **Single Source of Truth — analytics.py** (prevention A1): `closed_bars:30`, `compute_entry_score:313` (ML 40%/spread 30%/news 30% with renormalized weights, `apply_news_confidence_mult:44`), `ma_cross_direction:74`, `fused_regime_score:232` (ADX 45%/ER 35%/slope 20%), `mtf_fused_decision:204`, `htf_trend_decision:159`, `mr_entry_decision:178`, `volume_filter_pass:258`→`_obv_divergence:287`. Live (`signals.py`/`filters.py`) and backtest (`backtest.py`/`backtest_njit.py`) MUST call these — guarded by `tests/test_parity.py` (A2).
- **Template Method — execution** (`execution.py:_place_trade_inner:576` parameterized `is_mr` selects `atr_sl_mult` vs `mr_sl_atr_mult`, magic `20240706` vs `20240707`, comment `TrendBot` vs `TrendBot-MR`; `place_trade:916`/`place_mean_reversion_trade:929` are thin throttled wrappers; `manage_positions:416` owns TP-restore/breakeven/chandelier/scale-out and delegates close tree to `exit_decision.decide_exit`).
- **Deep module — exit decision** (`exit_decision.py:ExitIntent` frozen value, `decide_exit: priority MAX_HOLD>MR_EXIT>REVERSAL` pure, `max_hold_triggered: pure time`, `reversal_triggered: 0.25*ATR sub-profit guard`, `is_mr_position: magic/comment`, `_is_buy_position: int + MagicMock-aware`; `execution.check_max_hold` now delegates to `max_hold_triggered`; `manage_positions` fetches `mr_exit_hit`+`cur_atr` then calls `decide_exit` — seam is the test surface).
- **State Machine — exits** (`check_scale_out:108` RR-based partials with breakeven lock, `check_chandelier_exit:291` HH/LL±ATR*mult with two-stage `loose_mult→tight_mult` at `two_stage_min_r`, `check_breakeven:251` `be_atr_mult`→SL=entry, `check_max_hold:237`→`exit_decision.max_hold_triggered`, `check_mean_reversion_exit` RSI 50 cross).
- **Adapter/Proxy — MT5 edge** (`mt5_connect.py:426` `_MT5Proxy` lazy RPyC `:18812` `mt5server.exe`, `Market` adapter `LIVE_MARKET` with `symbol_info_tick/symbol_info/get_rates/order_send/get_deals`, `mt5_call:timeout wrapper`, `_update_dynamic_deviation:deviation 0.9×/1.5×`, `realized_pnl:deals[-1].profit` from `history_deals_get`, `fetch_rates_paged: backward paging chunk 80000`).
- **Cache-Aside** (`mt5_connect._rate_cache TTL 5 s`, `backtest._ML_DATA_CACHE/_ML_MULT_CACHE/_MTF_M15_MA_CACHE`, `risk._TRADE_STATS_CACHE TTL 30 s`, `state._ns_cache mtime`).
 - **Chain of Responsibility — 4 gates** now encapsulated in `entry_policy.py:EntryOutcome` (`evaluate_entry: G1 fused hysteresis→G2 MTF/single/MR branch→HTF 3-state→G3 ML→G4 sanity→MR cooldown` returning `blocked/block_reason`, `signal_entry/entry_atr/atr`, `confidence_mult/ml_conf`, `htf_size_mult/mtf_confidence`). `main.py:593` delegates per-symbol to `entry_policy.evaluate_entry` (single gate hysteresis update per cycle) before `manage_positions`; mapping of `block_reason`→`_filter_stats` preserves dashboard parity.
 - **Deep module — entry policy** (`entry_policy.py:EntryOutcome` value type, `evaluate_entry` owns ordering, `evaluate_signal_gate` exposes pre-close signal for `manage_positions`; regime/atr/trend_signal supplied to `manage_positions` even when entry blocked — exits independent).
- **Factory/Builder — config** (`config.py:load_config:161` INI→flat `cfg`, `symbol_cfg:530` `deepcopy`+`apply_symbol_strategy:473`+`apply_symbol_overrides:513`+`symbol_strategy:391` `[STRATEGY:<sym>]` via `SYMBOL_STRATEGY_MAP:33`+`KEY_MAP:61`, `apply_params_overrides:487` shared with optimizer, `_resolve_timeframe:98` static `_TF_CONSTANTS:89`, `validate_config:116` fail-loud).
- **Purged Walk-Forward / CPCV** (`optimizer_common.py:make_windows 24 mo IS/6 mo OOS`, `optimize_params.py:make_cpcv_windows IS24/purge1/OOS6 15 paths`, `overfit_stats.py:deflated_sharpe/PBO` DSR≥0.95/PBO≤0.50 gate).
- **Observer** (`journal:journal_open/journal_close` atomic `logs/trades.csv`, `discord_alerts:trade_open/close/partial/daily_summary`, `dashboard:write_dashboard_state`).

**ML stack:** `ml_features.py:FEATURE_COLS 44` (KAMA ratios, MACD EMA-based, `of_*` from `compute_orderflow_features` via M1 `close>open` per-bar buckets `attach_orderflow_features` before window slicing), `train_model.py:EnsembleModel(xgb,lgb,tft)` avg calibrated XGB+LGB+TFT (`tft_model.py:_TemporalFusionTransformer LSTM+MultiheadAttention seq_len 20`), `calibrate_models.py:Isotonic`, `drift_detector:schedule_warmstart`→`drift_retrain:warmstart_model` (unwrap `_CalibratedWrapper`, refit XGB `xgb_model=raw`, isotonic recalib).

**Backtest twin:** `backtest.py:Backtest` (`_precompute` MA/ATR/ADX/H4 resample/fused/MR RSI/ML mult, `run(fast=True)`→`backtest_njit._simulate_core @njit` 50+ scalars, `get_results`), `precompute_fixed` grid reuse; fast path disabled when `mtf_enabled=True`.
