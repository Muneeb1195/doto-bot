# config/

## Responsibility
Declarative live-trading source of truth — consumed by every `bot/` import and mutated by `scripts/download_models.py`. Single `settings.ini:380` file defines portfolio composition, per-symbol strategy overrides, regime/MTF/risk/execution global defaults, and `SYMBOL_POINTS` broker tick metadata. `credentials.ini` (git-ignored, `credentials.py:load_credentials` only reader elsewhere) holds MT5 login + Marketaux/Discord keys.

## Design
- **Single file, layered sections:** `[TRADING]` (fallback symbol H1 1% risk), `[STRATEGY]` (global defaults: `ma_type kama`, EMA 8/32, ATR 14, SL 1.0, RR 2.5, HTF H4 50/100 `misalign_mult 0.5`), 8× `[STRATEGY:<SYMBOL>.raw]` per-symbol overrides (BTC/SOL/XRP `ma_type vidya`, per-symbol `ema_fast/slow sl rr adx_trend scoring_min_entry 0.55–0.75` + `mtf_enabled false` for BTC/EUR/US500 `21/83/95`, `mr_rsi_oversold/overbought` 20/80 for crypto MR, `trading_enabled true` gate-paused flag), `[SCALE_OUT]/[CHANDELIER]/[BREAKEVEN]/[LIMIT_ENTRY]/[FINE_ENTRY]` exit tree (close_fractions 0.20,0.20 at RR 0.50/0.75, breakeven 0.25, CH lo/hi±ATR*2.5 partial 1.5 two-stage 3.5→1.5 at `two_stage_min_r 3R` + accelerate 0.20/5 bars, BE ATR 1.0 max 72 h, limit `score≥0.80` 30 cycles 0.5 spreads), `[LOGGING]/[PORTFOLIO]` (8 symbols `BTC,US30,GBPJPY,SOL,XRP,EUR,US500,XAUUSD` comma-list, `max_total 5 portfolio_risk 3/max_open_risk 5`), `[BACKTEST]` (spread×1.0, commission 976), `[SESSION]` (London 13–22, Asian 5–12 skip), `[VOLUME_FILTER]/[SPREAD_FILTER]/[TAPE_READING]/[CORRELATION]` (vol SMA20 κ1.2 OBV20, spf 0.30, tape 100 M1 imbalance 0.20 pressure 0.35/0.65 range 1.2, corr 24 h cap 50%), global toggles `[MTF]/[TREND_ENTRY]/[FUSED_REGIME] th 45 buf 3/[SCORING] min 0.55 weights ml:0.40/spread0.30/news0.30 buckets 0.85/0.60→mults 1.0/0.85/0.50/[ADX]/[ML_SIGNAL]/[MEAN_REVERSION] M30 RSI30/70 dev0.0 cooldown 2/[TAIL_RISK] 3σ 8% 60 m CB 15%/[EXECUTION_QUALITY]/[NEWS_SENTIMENT] 6h/[MT5] path/timeouts/[ORDER_EXECUTION] deviation 50 magics 20240706/20240707`), `[SYMBOL_POINTS]` (21 symbols `point/_tick/_vstep` populated by `scripts/export_mt5_data.py` + optimizer `fetch_m15_data`, consumed by `optimizer_common._load_csv_data` and sizing). Values are `ConfigParser` strings — typed via `bot/config.SYMBOL_STRATEGY_MAP` converters and `KEY_MAP` rename (e.g. `ema_fast_period→ema_fast`).
- **Loader — `bot/config.py:≈546`**: `load_config():161` parses `[TRADING]/[STRATEGY]/[SCALE_OUT]…` → flat `cfg` dict (`float/int/bool` coercion, lists split on `,`, weights dict), validates ranges (`validate_config:116` fail-loud `ema_fast<ema_slow`, `cb>tr` etc.), resolves TF via `_TF_CONSTANTS/_TF_MINUTES` + `_resolve_timeframe:98`; `symbol_cfg(cfg,symbol):530` `deepcopy(cfg)` + `apply_symbol_strategy:473` (merge `[STRATEGY:<sym>]` via `SYMBOL_STRATEGY_MAP:33` types) + `apply_symbol_overrides:513` (`SYMBOL_OVERRIDE_KEYS`) + `symbol_strategy` inheritance; `apply_params_overrides(settings,symbol,params,exclude):487` shared with `optimizer_common.build_params` + `auto_optimizer.write_settings` (239-key template, `_SWEPT` exclusion). Cold-copy semantics prevent cross-symbol contamination (critical for `main.py` per-symbol loop `deepcopy(cfg)` each 10 s).
- **Mutation contract:** `scripts/download_models._apply_strategy_params` is the ONLY writer to `settings.ini` at runtime (via `bot/auto_optimizer.load_portfolio → (symbols,ConfigParser) → update_symbol_strategy/set_trading_enabled → write_settings` atomic `.tmp+fsync+replace`). It toggles `trading_enabled=false` on hybrid gate-failure 2nd strike and tightens `scoring_min_entry+=0.15 cap 0.90` on 1st strike, resetting on pass; streaks keyed to `optimize-*` tag (`_last_opt_tag`) in `.symbol_streaks.json`. Manual `scp config/settings.ini` dev→server is forbidden (would revert applied params + drift; box has no `.git`). `scripts/export_mt5_data._save_symbol_info` is the second writer — it atomically upserts `[SYMBOL_POINTS]` once per symbol per export.
- **Credentials split:** `config/credentials.ini` (never committed, `.gitleaksignore` + CI secret-scan) read only by `bot/credentials.load_credentials` (env `MT5_ACCOUNT/_PASSWORD/_SERVER` overrides, `MARKETAUX api_key` fallback `MARKETAUX_API_KEY` env, `DASHBOARD_USER/PASS` mandatory for `dashboard/api.py`); `services/news_sentiment.load_api_key` reads same file.

## Flow
1. **Boot/read**: `bot/main.py:212` + `mt5_connect.ensure_mt5_connected` + `train_model/optimize_params/auto_optimizer` call `config.load_config()` → `[PORTFOLIO] symbols` drives symbol loop/matrix, `[STRATEGY:*]` drives `symbol_cfg` per symbol, `SYMBOL_POINTS` drives sizing (`risk.calc_position_size`) and optimizer CSV loader point/tick delta.
2. **Per-cycle clone**: `main` loop `for symbol in cfg["symbols"]: deepcopy(cfg) → symbol_cfg(cfg,symbol)` → feeds `signals.RegimeGate/signals.get_mtf_fused_signal/filters.check_ml_gate` etc. without mutating global.
3. **CI/server sync**: `optimize.yml` matrix reads `[PORTFOLIO] symbols` (ALL→portfolio self-sync, never hardcoded 24-universe); optimizer publishes `strategy-params.json/failed-params.json` → `download_models --dispatch/--fetch-only` applies via `auto_optimizer.write_settings` → `systemctl restart doto-bot`.
4. **Export**: `export_mt5_data` fetches `symbol_info.point/tick/volume` → atomic `[SYMBOL_POINTS]` write; `optimizer_common._load_csv_data` reads them to reconstruct CSV bars' point base.
5. **Validation preflight**: `bot/validate_entry_config.py` exits non-zero if missing `[STRATEGY:<sym>]`, out-of-range `scoring_min_entry`, `ma_type∉{kama,vidya,ema}`, `missing model_*.pkl`, etc. before long grid run.

## Integration
- **Consumed by:** `bot/main.py` (loop, guards, sizing), `bot/signals.py` (MA dispatch, RegimeGate, MTF/MR), `bot/filters.py` (`compute_entry_score` weights, ML gate thresholds), `bot/execution.py` (SL/TP, scale/chandelier), `bot/risk.py` (Kelly/vol), `bot/analytics.py` (weights, thresholds), `bot/regime.py` (ADX), `services/news_sentiment._load_portfolio_symbols` (watched symbols), `bot/optimize_params` + `optimizer_common.build_params` + `bot/auto_optimizer` (param matrix), `tools/diagnose_entry_rate._precompute_mtf_series` (H4 period).
- **Written by:** `scripts/download_models` (params/policy) + `scripts/export_mt5_data` (`SYMBOL_POINTS`) only — no direct `bot/` writes.
- **Env override:** `MT5_*` + `MARKETAUX_API_KEY` + `DASHBOARD_USER/PASS` env vars take precedence over INI; `GITHUB_REPO/API/TOKEN` for scripts only. `config/credentials.ini` git-ignored and excluded from `scripts/check_deploy_drift` hash (live-mutated file).
