# dashboard/

## Responsibility
Read-only observability layer — serves live trading state to browsers without touching the bot loop. FastAPI+uvicorn app (`api.py:44`) on `127.0.0.1:8501` behind `systemd doto-dashboard.service`, plus a single-page `templates/index.html` polled every 10 s. All data flows via file contracts (`data/dashboard_state.json` written by `bot/dashboard.py`, `logs/trades.csv`, `logs/bot.log`) — never direct import of `bot/`.

## Design
- **Auth gate** (`api.py:24`): `HTTPBasic` with `DASHBOARD_USER/PASS` env vars (`26` — `RuntimeError` if missing at import, `verify_auth:34` `secrets.compare_digest` constant-time, 401 `WWW-Authenticate: Basic`). Every `FastAPI(dependencies=[Depends(verify_auth)]:43)` request guarded; verified in `scripts/service-ctl.sh:health` (curl 401 without creds). Unit generated by `scripts/deploy-linux.sh` Phase 5 injects `EnvironmentFile` + checks vars.
- **File-contract reader + mtime cache** (`_cache:55` `{state,trades,state_mtime,trades_mtime}`): `load_state:78` stat `.st_mtime` → if changed `_load_state_raw:57` (`json.load` with `FileNotFound/JsonDecode→None`), `load_trades:90` stat → `_load_trades_raw:64` (`csv.DictReader`, `float(pnl/pips)` coercion, `sort exit_time desc`). Avoids re-parse on every poll.
- **Endpoints** (`api.py:102`):
  - `GET /api/state` → `load_state() or {}` — balance/equity/positions (with regimes), `_filter_stats`, `_corr_cache` snapshot from `data/dashboard_state.json` (written atomically by `bot/dashboard.write_dashboard_state` `.tmp+fsync+replace`, equity history 5000).
  - `GET /api/trades?limit 500` → `load_trades()` — journal tail (recent closes first, used for weekly stats `bot/weekly_summary.py`).
  - `GET /api/logs` → tail `logs/bot.log:115` last `262144 B` (seek+drop partial line), filter `re.compile(r"^\d{4}-.*\[(INFO|WARNING|ERROR)\]"):118`, return `[-60:]` — avoids reading multi-MB log on every poll (L1).
  - `GET /` → `TEMPLATE_PATH:53` `templates/index.html` as `HTMLResponse:135` (fallback “Template not found”).
- **Cache-Control** middleware (`_no_store_api:45` `Content-Type: http` → if `path.startswith /api/` set `Cache-Control: no-store` — prevents stale JSON on rapid poll).
- **Frontend** (`templates/index.html`) SPA: fetches `/api/state`/`/api/trades`/`/api/logs`, renders balance Rs. (PKR), equity/drawdown, per-symbol position table, filter diagnostics, correlation matrix, trade history, log tail. No build step — static HTML with inline JS (no `node_modules`).
- **Package hygiene** (`__init__.py` empty, `sys._base_executable` shim:1 + `JOBLIB_PARALLEL_BACKEND=threading:6` to silence sklearn joblib forking warnings when imported).

## Flow
1. Browser `GET /` → `api.index:135` returns `index.html` → JS `setInterval 10 s` polls `/api/state`+`/api/trades`+`/api/logs` with `Authorization: Basic` header.
2. Each API hit → `verify_auth:34` → mtime-checked cache read from `data/dashboard_state.json` / `logs/trades.csv` / tail of `logs/bot.log` → JSON/HTML response (no-store for `/api/*`).
3. `bot/main.py:826` `write_dashboard_state(all_positions, regimes)` writes the state file atomically each 10 s cycle; dashboard never writes back.
4. Publish sidecar `doto-dashboard-publish` (variant) can copy `data/dashboard_state.json` → `.dashboard_public/dashboard_state.json` for static export (see `dashboard/codemap` `templates/` note).

## Integration
- **Consumes:** `data/dashboard_state.json` (bot/dashboard.py), `logs/trades.csv` (bot/journal.py), `logs/bot.log` (`TimedRotatingFileHandler midnight UTC` in `bot/main.py:219`).
- **Upstream:** `bot/dashboard.py:write_dashboard_state` (atomic), `bot/journal.py`, `bot/main.py`.
- **External:** Browser via `http://<box>:8501` (bound localhost, reverse-proxied if exposed), `systemd` (`deploy-linux.sh` `doto-dashboard.service` + `service-ctl.sh:do_health` `curl 127.0.0.1:8501 → 401` probe), `scripts/redeploy.sh` restarts + polls `Bot state loaded`.
- **Isolation:** no `bot/` imports — testable without MT5 (`tests/test_dashboard.py` mocks file layer).
