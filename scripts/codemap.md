# scripts/

## Responsibility
Home-server ops + GitHub Actions data/artifact pipeline — NOT part of `bot/` runtime. Owns MT5 history export, data release publishing, model/param dispatch & fetch (train vs optimize dual release streams), drift detection, plateau selection, and server provisioning. Runs via `systemd timers` on `192.168.1.15` (`doto-orchestrate` monthly, `doto-download` hourly) and one-shot `deploy-linux.sh`.

## Design
- **Two-mode orchestrator — `download_models.py:573`** the core. `_common._setup_logging + _gh:3` helpers deduplicate `gh` CLI wrapping (`GITHUB_TOKEN→GH_TOKEN`).   - Hybrid gate-failure policy (`FAILURE_PAUSE_STRIKE 2`, `ENTRY_TIGHTEN_DELTA 0.15 cap 0.90:61`): `_apply_passed_params:179` (reset streak, `set_trading_enabled true`), `_apply_failed_params:209` (streak keyed to `opt_tag` — `LAST_TAG_KEY` skip if already applied, 1st strike tighten `score+0.15`, 2nd+ `set_trading_enabled false` pause, params untouched on pause). `_apply_strategy_params:269` orchestrates both via `auto_optimizer.load_portfolio → (symbols,ConfigParser) → write_settings` atomic, `_save_streaks` only after settings write succeeds. `_extract_models:345` temp `tarfile` flatten `models/models/→MODELS_DIR` (never prunes stale), `_restart_bot:324` `systemctl --user restart doto-bot` (Linux) or `schtasks` fallback.

## Flow
1. **Monthly `doto-orchestrate` → `download_models --dispatch`**: `_push_market_data` exports M1/H1/M15 via MT5 → `push_data` creates `data-*` release → `gh workflow run train.yml` wait 45 m → `gh workflow run optimize.yml mode=monthly` wait 8 h → `fetch` downloads `models.tar.gz` + `strategy-params.json/failed-params.json` streaming → flatten models → `apply_strategy_params` (passed reset + failed hybrid with streak keyed to tag) → restart bot. Hourly `doto-download --fetch-only` reuses `fetch` (pure urllib, tag equality short-circuit).
2. **Export timer 6 h** → `export_mt5_data --no-git` (5.1 y H1/M15/M1) → `git add/commit/push` if `--no-git` not set.
3. **Drift** on box → `check_deploy_drift --repo Muneeb1195/doto-bot --ref main` SHA256 compare vs codeload (exit 0 sync/1 drift/2 error).
4. **Provision once** → `deploy-linux.sh` idempotent phases 0–10; subsequent `service-ctl.sh start|stop|status|health` or `redeploy.sh` after `scp`.

## Integration
- **GitHub:** REST `api.github.com/repos/*/releases*` (urllib) + `gh run list/view/workflow run/release create/upload/delete/api` + `codeload` tar.gz; PAT `GITHUB_TOKEN` via `~/.config/doto-orchestrate.env` (`EnvironmentFile`), not `config/credentials.ini`; `GITHUB_REPO/GITHUB_API/GH_BINARY` overrides.
- **MT5:** `bot/config.load_config + mt5_connect.ensure_mt5_connected + fetch_rates_paged` (M15/M1) + `bot/mt5 symbol_select/copy_rates_range` (H1) via `mt5linux` RPyC `:18812`.
- **Bot:** `bot/auto_optimizer.{load_portfolio,update_symbol_strategy,set_trading_enabled,write_settings}` (ConfigParser mutation), `bot/filters.load_ml_models` reads `models/model_*.pkl/.calib.npz`, `config/settings.ini [PORTFOLIO]/[SYMBOL_POINTS]` bidirectional.
- **Systemd:** `~/.config/systemd/user/` units (`xvfb-mt5/mt5/mt5server` + `doto-bot/dashboard/news/backup/download/orchestrate` timers) controlled by `download_models._restart_bot` + `service-ctl.sh` + `redeploy.sh` polling `logs/bot.log`.
