# tools/

## Responsibility
Dev-side diagnostics for live/backtest parity and entry-signal strictness — standalone `python tools/*.py` invoked manually (never by systemd/CI). Replays the exact live gates on historical bars, or asserts `Backtest(fast=False)` vs `fast=True` JIT produce bit-identical trades.

## Design
- **Shared replay kernel — `_common.py:156`** deduplicated helpers (once copy-pasted). Adds `bot/` to `sys.path:19` and imports pure `analytics`+`indicators` (no MT5 state). Four fns:
  - `_mtf_signal_local:24` per-bar mirror of `signals.get_mtf_fused_signal`/`backtest._get_mtf_signal`: `h4_a[i]` EMA(period) bias with `0.5*ATR` neutral band `43`, H1 `fast/slow` crossover `56` must agree with H4 direction (1/-1) `60`, M15 `m15f/m15s` crossover timing `66` → `crossover` if `m15_cross==h1_cross` `76` else `pullback` (or filtered if non-zero disagree `78`), degraded if M15 `None` → pullback, guards NaN/ATR≤0/i<2.
  - `_crossover_local:83` KAMA/VIDYA via `calc_ma(dispatch ma_type:84)` + `calc_atr` on `win.iloc[-2/-3]` (closed bars).
  - `_mr_local:100` mean-reversion replay (`get_mean_reversion_signal` decision only): needs `htf_ema_slow+mr_rsi_period+atr+5` bars `109`, `calc_rsi(win.iloc[:-1])`, `cur_price win.close[-2]`, `htf_ma calc_ma(htf_ema_slow)`, `dev mr_htf_deviation`, buys if `rsi<oversold && price>htf*(1-dev)` `125`, sells if inverted — MR cooldown (≥2 consec losses `mr_cooldown_bars 2 h`, stateful P&L) NOT replayed (documented).
  - `_exec_sanity_local:132` Gate 4 replay (`filters.check_execution_sanity`): `volume_filter_pass(win,signal,cfg):146` on last closed bar (`analytics` shared kernel), then bar-spread gate `spread*point/ATR > spf_max_ratio 0.30:154` (`point` defaults `0.01`), tape sub-gate assumed pass (needs live M1).
- **`diagnose_entry_rate.py:248`** quantitative pipeline debugger. Imports `_common` fns + `analytics.fused_regime_score/compute_entry_score` + `backtest._get_mtf_m15_mas` + `signals.RegimeGate/check_htf_trend` + `mt5_connect get_rates/fetch_rates_paged` + `config load_config/symbol_cfg`. `GATES = signal/htf/htf_soft/score/exec/passed:59`. `_precompute_mtf_series:62` mirrors `backtest._precompute`: H1 fast/slow+ATR arrays, H4 resampled `4h` OHLC from `df.set_index(time)` + `calc_ma(h4_period100)` shifted `h4_shift = index[1]-index[0]` then `ffill` aligned to `df[time]`, M15 via `_get_mtf_m15_mas` (bit-parity). `evaluate_symbol:106` warmup `max(ema_slow,atr,mtf_need100*4)+atr+60`, adaptive bar count `target = need+years*365*24*0.6`, fallback shrink `1.0/0.5/0.25/0.1` then 400 bars, M15 via `fetch_rates_paged` (graceful fallback print), loop `i need..n-2` advancing `RegimeGate(threshold,buffer)` every bar `155` → Gate2: if `gate_open` → MTF (`_mtf_signal_local`) else single-TF, else if `mr_enabled` try `_mr_local` (is_mr) then fallback MTF/crossover (main.py parity) → `check_htf_trend` (block/soft) → `compute_entry_score` `min_score = scoring_min_entry + (0.03 if is_mr)` → `_exec_sanity_local` → `counts[passed]++`. `main:203` argparse `--symbol --years --config`, per-symbol table `signal/htf/soft/score/exec/pass/pass%`, TOTAL rollup, note lower-bound warning.
- **`parity_check.py:50`** fast vs reference smoke: synthetic `bt_df:6` `n 1500` random walk `close cumsum randn 0.4`, H1 freq, `PARAMS:23` deterministic (kama 12/48 sl2 rr2 etc including scoring/volume etc), loop `fast False/True` `Backtest(df,params).run(fast=fast)` → `equity[-1]` + `pnls round 4` → prints `PNL MATCH/EQ MATCH` (verifies `backtest_njit._simulate_core @njit` bit-exact when `mtf_enabled False`).
- **`trace_parity.py:49`** first-divergence debugger: fixed seed 7 trending `+0.02 n`, 1500 bars, `base` params (`volume_filter False` to avoid threshold jitter), same `Backtest` both modes → zipped `entries (entry_bar,exit_bar,exit_reason,type,pnl)` → walk until `r[k]!=f[k]` dump `FIRST DIVERGENCE` + `k-3..k+3` context for both streams, else `identical`; pinpoints JIT drift without scanning full log.

## Flow
1. **Diagnosis**: `python tools/diagnose_entry_rate.py --symbol XAU500.raw,BTCUSD.raw --years 1` → loads `settings.ini` per-symbol `symbol_cfg` → pulls H1 + optional M15 from live MT5 → `_precompute_mtf_series` aligns H4/M15 → advances `RegimeGate` → replays Gate1–4 mirroring `main.py` order → prints rejection breakdown (how many candidates each gate kills, pass% lower bound due to tape/MR-cooldown approximations).
2. **Parity**: `python tools/parity_check.py` / `python tools/trace_parity.py` (no MT5, synthetic data) → instantiates `Backtest` twice (reference Python loop vs JIT `backtest_njit._simulate_core`) → asserts equality of trade PnL tuple + equity terminal.
3. **Shared kernel** guarantees replay fidelity: all helpers call `analytics.closed_bars/ma_cross_direction/volume_filter_pass/fused_regime_score` — same functions live + backtest use (divergence prevented by `tests/test_parity.py`).

## Integration
- **Consumes:** `bot/config.load_config + symbol_cfg`, `bot/analytics.*` + `indicators.calc_*`, `bot/signals.RegimeGate/check_htf_trend`, `bot/backtest._get_mtf_m15_mas/Backtest`, `bot/mt5_connect.get_rates/fetch_rates_paged/mt5.TIMEFRAME_M15` (live MT5 via `mt5linux :18812`), `data/history` indirectly via MT5 fetch.
- **Used by:** developers to answer “are entries too strict?” (diagnose) and to verify JIT parity before optimizer/CI; `bot/optimizer_common.run_bt(fast=True)` depends on `Backtest` parity holding; CI `tests/test_parity.py` guards same property gate.
- **Not deployed:** server never runs `tools/`; `scripts/_archive` sweeper kept separately.
